| [5082](https://www.rfc-editor.org/rfc/rfc5082) | GTSM | `ttl_security` |

## Not supported

- Address families other than IPv4 and IPv6 unicast (no VPN, EVPN, flowspec, multicast).
- Route reflection, route servers (`role = "rs-client"`), confederations.
- Enhanced route refresh (RFC 7313), outbound route filtering (ORF, RFC 5291), ADD-PATH, BFD, TCP-AO.
- With `[kernel]`: routes whose next hop is of the other family (RFC 8950) are not installed.

The protocol code is the `ansage-bgp` crate, see [Crates](/docs/development/crates).
