ansage is a BGP speaker that announces your own prefixes (anycast services, a VPS's IPv6
range) to one or more routers. For now it only announces: it does not re-export routes yet.
With `[kernel]` it installs the best routes it learns into the Linux routing table.

```toml title="/etc/ansage/ansage.toml"
asn = 64500
router_id = "203.0.113.1"
announce = ["192.0.2.0/24", "2001:db8:1::/48"]

[[neighbor]]
address = "10.0.0.1"
asn = 64501
```

## What it does

- Announces the prefixes from the config, plus `ansage announce` / `ansage withdraw` at runtime.
- Drains a site (RFC 8326) before maintenance, so traffic moves without a hard withdraw.
- Upgrades without dropping routes (`ansage upgrade`, Graceful Restart).
- Optionally installs the best learned routes into the Linux routing table (`[kernel]`).
- Reports through `ansage show`, Prometheus metrics, a JSON API and live events.

## What it does not do (yet)

<Callout type="info" title="No re-export yet">
ansage starts with announcing: it exports only its own prefixes (`export = "own"`) and does not
pass learned routes on yet. Re-exporting is planned for a later release. Health checks live
outside ansage, see [Health checks](/docs/guides/health-checks).
</Callout>
